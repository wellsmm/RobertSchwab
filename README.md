# Robert Schwab website

A static, accessible multi-page demo website built from the Robert folder in the owner's personal Google Drive.

## Pages
Home, Apparel, Jigs & Tackle, Gallery, About, Contact.

## Design
Colors derived from the two provided Schwab logos: pine green, deep forest, rust, ochre and parchment. On the home page the fish face one another, with the apparel logo on the left and Jigs logo on the right.

## Before publishing as an operational business site
- Replace demonstration copy, product names, specs, prices and brand biography with Robert-approved facts.
- Connect the contact form: edit `const endpoint=""` in `assets/site.js` to a validated Formspree endpoint or other protected backend. The demo form intentionally does not transmit data without this setup.
- Confirm rights to logos/photos, business details, fulfillment and shipping policies as applicable.
- Review accessibility, content and mobile layouts with Robert.

## Deployment
Host repository root using GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → main / (root).
