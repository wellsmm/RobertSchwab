# Robert Schwab — Apparel & Jigs

A responsive, accessible showcase for Schwab apparel and Schwab Jigs, using the original brand artwork and photographs from the **Robert** folder in the owner's personal Google Drive.

## Pages
- Home — both brand marks, with fish facing one another
- Apparel — products and photographs
- Jigs — jigs and fishing-related photographs
- Galleries — original project images grouped by category
- About — editable sample biography and craft story
- Contact — accessible inquiry form (requires a configured Formspree endpoint to deliver submissions)

## Setup
This is a static GitHub Pages site. In repository **Settings → Pages**, select **GitHub Actions**. The provided workflow converts source HEIC photos to browser-compatible JPEGs and deploys the site. Configure the contact form by replacing the empty endpoint in `assets/js/site.js` with a verified Formspree form endpoint. Text clearly marked as demo is intentionally placeholder copy.

Design uses the logos' forest green, cream, copper, brown, and muted gold tones. No prices, inventory, or contact details have been invented.
